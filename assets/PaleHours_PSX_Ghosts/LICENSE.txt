HOW THIS WAS MADE
-----------------
Every character in this pack is AI-generated. The bodies were generated with MakeHuman (MPFB, whose
output is CC0) from parameter values chosen by an AI system, decimated and rigged by scripts that an AI
system wrote. Every texture is an AI painting (OpenAI image model) made over the model's own silhouette
and projected back onto the mesh. The skeleton and the animation clips are the CC0 Quaternius Universal
Animation Library (see NOTICE.txt). The storefront listing states the same thing: Code = yes,
Graphics = yes, Sounds = no, Text and Dialog = no.
